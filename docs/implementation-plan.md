# Polysyne marketing website

The supplied brief authorizes a complete implementation in this clean Next.js starter.

1. Establish a company-first design with an interlocking geometric Polysyne symbol, dark graphite surfaces, generous Geist typography, restrained indigo and cyan details, and distinct section compositions.
2. Build shared navigation, footer, calls to action, motion leaves, and an interactive labeled product concept. Implement all five requested routes using server-rendered page content.
3. Add React Hook Form and shared Zod validation, honest disconnected states, and a server-only HTTP adapter for future FastAPI lead intake. Bound request bodies, check origins, rate-limit requests, and preserve privacy.
4. Add per-route canonical and social metadata, generated share imagery, sitemap, robots, verified-only organization data, configurable company content, and deployment documentation.
5. Verify lint, TypeScript, production build, meaningful form/API tests, and browser interactions at desktop/tablet/mobile sizes. Record actual findings without claiming unmeasured performance.
